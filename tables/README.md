# Tables for the SentiLight capacity-search paper

> **Not part of this record.** The generator scripts retain code paths for a human-evaluation figure and table (`F10_human_evaluation`, `T12_human_evaluation`) that belonged to an earlier draft. The submitted manuscript reports no research involving human participants, so those outputs and their input data are excluded here and the corresponding code paths will not run.

All ± values are mean ± sample SD (n − 1) across independent training seeds; the number of seeds is given per row or in the caption. Statistical intervals are computed from the per-seed values (paired-seed t intervals as primary analysis; hierarchical bootstrap and DerSimonian–Laird pooling as sensitivity analyses).

Generated by `make_tables.py` from `Implement_New_Android_v6/backend/reports/` (and the anonymous survey workbook). Each table ships as CSV and Markdown. T = main text, S = supplementary.
