# Figures for the SentiLight capacity-search paper

> **Not part of this record.** The generator scripts retain code paths for a human-evaluation figure and table (`F10_human_evaluation`, `T12_human_evaluation`) that belonged to an earlier draft. The submitted manuscript reports no research involving human participants, so those outputs and their input data are excluded here and the corresponding code paths will not run.

Error bars and ± values are mean ± sample SD (n − 1) across independent training seeds; open markers are individual seeds; seed counts are stated in each caption.


Generated by `make_figures.py` from the analysis files in `Implement_New_Android_v6/backend/reports/`. Each figure ships as PNG (300 dpi) and PDF, with the plotted numbers in `data/<name>.csv`. Only final results are plotted (five seeds where available; three-seed cells drawn hollow).

## Graphical abstract

`GA_graphical_abstract.png/.pdf` (made by `make_graphical_abstract.py`; numbers in `data/GA_graphical_abstract.csv`): three panels — (1) from the nominal 1.3 × 10¹¹ actuator space to the effective action set K_eff = 240 (a task descriptor, not a width); (2) K-series evidence: smallest tested width passing 60 % exact vs K_eff under the fixed step budget (T04) and the identical-utterance comparison at d = 384 under both budgets (S07); (3) outcome: selected d384 L8 V4k model (86.5 ± 1.8 %, 15.7 M) vs the deployed architecture retrained (80.8 ± 3.6 %, 23.4 M), with quantized size and CPU latency (T10, T11). Intended for the IEEE Access graphical-abstract upload.

`GA_graphical_abstract_660x295.jpg`: compact version at the IEEE-suggested 660 × 295 px (JPG, < 45 KB) for the submission system's graphical-abstract field (question, K_eff–width chart, outcome box).
