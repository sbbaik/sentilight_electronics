# Figures of the manuscript

Extracted from the submitted Word file at the resolution used for submission, one file per figure, in document order.

- `Figure01.png` — Figure 1. Study design. Executable-action enumeration and per-action exposure define task information for a multi-seed capacity search. The selected configuration is then examined through software integration, deployment measurements, three constructed evaluation distributions and integration with the physical five-bulb platform.
- `Figure02.png` — Figure 2. SentiLight software and device control path. The Android application transmits text or transcribed speech to the FastAPI service. After model inference, schema validation and membership testing against the 240-entry action catalogue, an admissible tuple returns to the client for Tasmota execution. Out-of-policy outputs are withheld at the service; capacity experiments and CPU latency are measured on this service path.
- `Figure03.png` — Figure 3. Effective action count, model width and training schedule. Under a fixed number of steps, the smallest tested width above the descriptive 60% line increases across the nested policies. Under matched presentations per action, mean accuracies for the larger policies are closer at wider widths, without seed-level confirmation of the attenuation. Filled and hollow markers denote five and three seeds, respectively.
- `Figure04.png` — Figure 4. Width, depth and vocabulary experiments. With the original 24k tokenizer, the largest supported neighboring width increase lies between d = 224 and 256. At d = 384 with that tokenizer, no reliable adjacent accuracy gain is detected beyond L = 4, while latency increases with depth. Under the tested pretraining budget, the 4k natural-text tokenizer has the highest development accuracy among the natural-corpus sizes. Connecting lines join measured configurations only.
- `Figure05.png` — Figure 5. Development-set exact match versus parameter count for the evaluated configurations. The selected d = 384, L = 8, V = 4k model combines the highest development mean among the leading compact candidates with the lowest corresponding seed variation. Selection applies to the tested grid and is not a global architectural optimum.
- `Figure06.png` — Figure 6. Exact-match results across three constructed input distributions. Development templates support model selection; unseen frames test new sentence structures with known policy vocabulary; post hoc machine paraphrases provide a stronger synthetic wording shift. These estimates do not measure accuracy on spontaneous user utterances.
- `Figure07.png` — Figure 7. Paired-seed development-set differences after mixed-bit export. Both generative configurations satisfy the prospectively specified ±3 percentage-point equivalence test.
- `Figure08.png` — Figure 8. File size, loading and CPU response for tested decoder exports. Mixed-bit storage and loading improve, while inference remains similar because weights are dequantised on load. Four CPU threads were used on the local service.
- `Figure09.png` — Figure 9. Implemented SentiLight platform. (a) The five-bulb laboratory platform; (b) the Android client with model-to-bulb assignments. The photograph and screen capture document the physical implementation. The software and device control path is shown separately in Figure 2. Capture provenance is supplied with the research artifacts.
